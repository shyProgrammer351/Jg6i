문제

아래 설명된 의미에 해당하는 용어를 쓰세요 
 비교연산자로 두 변수값이 같으면 참을 반환하고 다르면 거짓을 반환  

 삼항연산자에서 조건식이 참인지 거짓인지 확인하는 기호  

 삼항 연산자에서 조건식이 참과 거짓일 때 실행하는 명령문을 구분하는 기호  

 곱하기 연산자  

 더하기 연산자  

 0 ~ 1 사이의 실수 중 임의의 수 하나를 반환하는 메소드  

 객체가 없음  

 -2, -1, 0, 1, 2 등의 정수를 표현하는 기본자료형  

 다른 패키지 클래스를 가져오기  

 입력, 날짜, 등 유용한 클래스를 제공하는 패키지  

 데이터를 읽어오는 기능을 제공하는 클래스  

 클래스 객체를 메모리에 생성  

 키보드와 같은 표준 입력  

 리소스 닫기 메서드  

 주어진 내용을 모니터에 출력하는 메서드  

 주어진 내용과 줄바꿈(new line) 문자를 모니터에 출력하는 메서드  

 정수형 데이터를 읽어오는 메서드
